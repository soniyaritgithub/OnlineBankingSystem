# SmartBank - Full Stack Online Banking Platform 🚀

## Overview

A full-stack banking platform with secure authentication, UPI transfers, transaction management, loan modules, and admin dashboard.

## Live Demo

Frontend:
https://online-banking-system-eight.vercel.app/

Backend:
https://onlinebankingsystem-qguw.onrender.com/

## Features

- User Authentication (JWT)
- UPI Payments
- Money Transfer
- Debit Card Module
- EMI Calculator
- Loan Management
- Admin Dashboard
- Transaction History
- Responsive UI

## Tech Stack

Frontend:
- React.js
- Vite
- Tailwind CSS
- Axios

Backend:
- Django
- Django REST Framework
- JWT Authentication
- Node.js
- Express.js

Database:
- MySQL

Deployment:
- Vercel
- Render
